# 🛍 MyShop – E-Commerce Website

Live Demo ➤ https://e-commerce-store-20.netlify.app

## 🚀 Features
- Homepage with hero slider
- Products listing
- Category filters
- Price range & sort options
- Product details page
- Search feature
- Add to Cart with local storage
- Checkout & Order confirmation
- Responsive design

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage
- Netlify Deployment

## 📄 Pages Included

- Home (index.html)
- Products Listing (products.html)
- Categories (category.html)
- Search (search.html)
- Cart (cart.html)
- Checkout (checkout.html)
- Order Confirmation (order-confirmation.html)
- Contact Us (contact.html)
